# Memory and handoff design — Movies_Projects

Status: design approved in chat (approach B, Phase 0 first, English). Phases 1–4 await review of this document. Not committed.

## Intent
Give every agent and conversation a trustworthy resume point and a complete handoff after each task, so the short film (*The Table Between Centuries*) can be finished without re-deriving state. Truth stays in the existing canonical files; new views are derived or tightly scoped.

## Constraints (from AGENTS.md and the owner)
No deletion, move or rename of folders or media; preserve originals and history; no commit/push unless Andre asks; no credentials in memory; no change to approvals, tasks, ledger or manifest from this work; zero-full-face and paid-submission rules unchanged; concurrent agents share the checkout.

## Problems found (verified 2026-10-09)
Five competing entry points; 32 KB append-only STATE.md with stale "Next actions"; two decision namespaces (`memory/decisions.json` D01–D05 vs `00_brief/decisions` D01–D16); risks untouched since bootstrap; approval flags duplicated in manifest and approvals.json; board blocker text older than the current direction; handoffs never marked ingested and with drifting fields; money state only in prose; relayed approval (D16) without a machine-readable Andre-only gate list; uncommitted work; eight plan versions with no "current" pointer.

## Design (approach B: convention + read-mostly tooling)
Layers: rules (`AGENTS.md`) → canonical machine state (manifest, board, approvals, decisions, ledger, registry) → one short resume surface (`memory/STATE.md`) → append-only history (`memory/history/`, `session-log.json`) → handoffs (`agents/handoffs/`).

### Phase 0 — Reconcile (done, docs only)
`STATE.md` rewritten to ≤80 lines with old copy preserved; `decisions.json` marked superseded with `LEGACY-` IDs; `risks.json` refreshed (R01–R05 kept, R06–R10 added); banners on `CONTINUE_HERE.md` and `START_HERE.md`; one line in `AGENTS.md`; handoff and session-log entry written.

### Phase 1 — Handoff v2 and role briefs
Template v2 keeps all v1 fields and adds: `readFirst`, `claims[]` (statement + evidence path + sha256), `nextActions[]` (role + action), `blockers[]`, `andreOnlyGates[]`, `proposedDecisions[]`, `contributorKind` (`registry-role` | `contributor`), `ingest` (`pending` | `ingested` + by/at). Each role brief gains: reads, writes, may-not, definition of done. Codex, ChatGPT built-in, Antigravity and similar tools are `contributor` with no authority. Add a machine-readable list of Andre-only gates to `approvals.json` only through the producer.

### Phase 2 — Tooling (`scripts/manage.py`, stdlib, tests)
`resume` prints the session-start digest; `handoff check` validates v2 fields; `handoff ingest` records producer reconciliation; `lint` reports ID collisions, manifest/approvals mismatch, stale blocker text vs newer handoffs, uningested handoffs, uncommitted deliverables, missing current-plan pointers. Lint is advisory except for hard contradictions.

### Phase 3 — Per-task close-out loop
1. Write handoff (base and result hashes). 2. Producer ingests. 3. Update board/ledger/decisions through the owner. 4. Append a session-log entry. 5. Run `validate`, `lint`, tests. 6. Stage and review a commit only when Andre asks.

### Phase 4 — Backfill and use
Ingest the 22 existing handoffs, add a current-plan pointer for `07_generations/plans/`, then apply the loop to T13 and the four remaining chapters.

## Open decisions
Single owner of manifest/board/approvals/ledger (director proposes the producer session). Whether `STATE.md` is hand-curated (current) or generated by `resume` after Phase 2. Whether Phase 3 step 6 uses per-task commits once Andre allows commits.
