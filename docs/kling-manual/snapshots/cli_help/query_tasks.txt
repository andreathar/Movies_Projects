MCP tool: query_tasks

Description:
Query the status of a Kling AI generation by generation_id. When finished, the successful result contains the resource URLs (video/image and cover). URLs expire in 24 hours, inform user to download in time. 'AI Generated' top-left watermark inherits user web config (separate from bottom-right Kling logo controlled by url / urlWithoutWatermark in query result). Modify config on web manually, wait 30s, then re-query finished tasks to fetch updated results.
