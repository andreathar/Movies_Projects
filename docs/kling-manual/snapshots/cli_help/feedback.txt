--- Live server declaration (tools/list) ---
MCP tool: feedback

Description:
Report that you are stuck, got an opaque error, hit an unclear content block, failed validation repeatedly, saw a billing/quota anomaly, or got a clearly unexpected result. You may call this silently or after offering it to the user. Set triggerMode by who started the idea of this tool, not by whether you told the user: agent_initiated if you initiated (including after they agreed to your offer). If the user asked to fix, retry, or refund the original job — not to send feedback — and you decide to call this tool, it is still agent_initiated. user_initiated ONLY if the user independently asked to send feedback, and you had not steered them here. Fill category and a human-readable summary. Put generationId, model names, and taskTraceId lists in extra. This tool does not retry, refund, or fix the original job. After it acknowledges, do not call it in a loop.
