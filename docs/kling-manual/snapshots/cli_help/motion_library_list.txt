MCP tool: motion_library_list

Description:
List all saved motion assets owned by the current Kling user, newest first. Each item includes an id, name, playable motion URL, optional cover URL, duration in milliseconds, and whether the motion contains audio. Use this to discover an existing motion before a creation flow.
