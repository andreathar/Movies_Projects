# Frontend navigation

Authority: current source files, `AGENTS.md`, and `docs/PRODUCTION_PLAN.md`; this note is an index, not production state. Reviewed after the 2026-10-15 component extraction. Recheck these paths when changing module boundaries.

- `sites/movies-demandas/app/page.tsx` authenticates and loads the initial site snapshot through `lib/workspace-store.ts`; `app/dashboard.tsx` owns view selection/modal routing. `app/_dashboard/views/` and `modals/` hold presentation and local form state; `use-workspace.ts` owns server state/revision feedback. Site tasks/comments are D1 state, separate from canonical film records.
- `lib/model.ts`: package/action schemas, site transitions, import comparisons, and planning-package precedence. Newer/equal reviewed imports containing a plan take precedence over an older bundle; the bundled plan can fill an older snapshot or a legacy import with no plan, without changing saved records. Neither import approves images or grants spend.
- `app/production-plan-panel.tsx` composes `app/_production-plan/` tabs. `baseline-reference.tsx` displays exact image bytes/enlargement; `reference-decision.tsx` captures explicit human decisions; `use-reference-reviews.ts` reads current local decisions and saves against a captured plan hash.
- Local dev only: `scripts/reference-review-server.mjs` checks loopback/local identity/origin and exposes canonical decision reads/writes through `reference-review-store.mjs`. New immutable decision evidence precedes an atomic plan replacement; the selected generation-plan pointer checksum is refreshed without adopting a plan or changing paid release. Request IDs are idempotent, including recovery of an interrupted checksum update. Image hash, plan hash, and declared scope bind each decision. No automatic creative approvals. `scripts/baseline-media.mjs` serves only allowed exact-hash images. Hosted builds have no canonical local-write route.
- `scripts/export-production.mjs` and `export-workspace.mjs` derive bundled JSON using `export-common.mjs`; `check:data` checks included consistency, exporters `--check` verify local freshness. Runtime decision saves refresh the production export; failures are reported while canonical decisions remain readable.
- `scripts/local-review.mjs` owns only its recorded local process; `review-readiness.mjs` uses a stable JSON readiness endpoint, not component text. `tests/reference-review.test.mjs` uses disposable canonical fixtures; model/tab/modal/client tests cover their own boundaries. `tests/api.test.mjs` writes a live site workspace and is not a harmless production smoke test.

Use live symbol/reference tools for callers; do not copy task counts, approval states, active ports/process IDs, balances, credentials, or conversation histories into this note. Canonical ownership map: `mem:production_architecture`.
