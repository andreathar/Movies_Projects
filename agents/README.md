# Agent Roles

`registry.json` indexes the ten local role briefs. The producer integrates canonical records. The coordinator dispatches and proposes changes; it does not write those records. These documents do not start autonomous agents. The parent passes the relevant brief, exact film/task paths, current state and allowed scope into an explicit Hermes delegation. Reviewers return findings; the parent verifies artifacts and applies task transitions. Only the producer can run an approved paid shot.

No daemon, cron, agent credential store or third-party agent process is created.

Local source editing is now authorized within assigned responsibilities. Follow [LOCAL_AGENT_HANDOFF.md](../docs/LOCAL_AGENT_HANDOFF.md); preserve other agents' work and record input/output hashes using [agent-handoff-v2.json](../shared/templates/agent-handoff-v2.json). Historical deliveries that used schema 1.0 stay in the handoff folder. Read-only defaults in individual reviewer briefs yield to an explicit local editing assignment, while producer-only state changes and paid submission restrictions remain in force.
