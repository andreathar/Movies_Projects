# Ensaio local de continuação — sem produção

**ENSAIO, SEM PRODUÇÃO.**

Esta pasta é um rascunho independente, não um clone do filme anterior. Os arquivos são editáveis. Aprovações, orçamento e mídia começam vazios. Ainda não satisfaz o manifesto de uma produção.

Ao definir o briefing, o produtor cria o manifesto, plano de tomadas e dependências do novo episódio, valida sua consistência e só então registra a produção.
