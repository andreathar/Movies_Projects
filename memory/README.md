# Local Project Memory

This workspace uses local files, not global profile memories or a new Cognee dataset. `projects.json` points to each film's resume state. Read the active film's `memory/STATE.md`, `00_brief/decisions/` and risks before acting. `projects.json` `decisions` points at that directory. `legacyDecisions` is the superseded `memory/decisions.json` bundle (`LEGACY-` ids). Task progress stays in the canonical board and accepted media in the manifest; memory must link to those rather than claiming contradictory progress.

After verified changes append a concise session entry and update the resume point. Keep no credentials, raw authorization headers, voice tokens or private secrets here.
