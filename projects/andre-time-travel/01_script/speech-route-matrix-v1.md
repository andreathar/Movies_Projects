## 4. Recommendation — cheapest viable 5-second visible-speech test

The only route whose declared inputs match the production need (an accepted Kling Andre clip + the already-consented "Athar" clone audio) is E2. Cheapest version: trim the existing, already-paid VT-01 English line to ≤5 s with `ffmpeg` (no new TTS spend), pair it with one accepted-or-candidate 5 s Kling clip of Andre at the table (generated via `kling image_to_video --model kling-video-v3_0_turbo` from an approved still, `--duration 5 --resolution 720p --imageCount 1`, prompt specifying closed-mouth listening then calm speaking — no `enable_audio` on turbo, so the base is silent and cheap; cost known only from `creditsConsumed` on submission, within the Kling balance of 6,981 and needing producer approval), then run **Veed Lipsync** (docs: "fast, affordable") on ElevenCreative with that video + audio, reading the on-screen cost indicator before confirming; upgrade to Sync 3 / Sync Lipsync 2 Pro only if the Veed pass fails on beard/teeth/jaw. Reviewer compares processed vs original frame-by-frame per language-strategy step 4. Do **not** spend Kling credits testing the generic `--audio` flag: no model declares it, and a rejected-or-charged probe resolves nothing. Zero-vendor alternative (K1: `kling-video-v3_0` with `enable_audio=true` and a spoken line in the prompt) proves only that Kling can animate a mouth with its *own* voice — useful as a likeness-stability check but not a proof of the clone/translation route. All of the above are proposals; ElevenLabs video spend has no authorization yet.
