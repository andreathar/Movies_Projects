# The Table Between Centuries — preproduction atlas v1

Open `index.html` to browse the visual boards, filter by scene and listen to the four opening references. Each card opens as a full-size PNG.

- `reference-atlas.pdf`: 16 boards, including the seven scene boards, six character boards and wardrobe comparison.
- `storyboard-cards.pdf`: 41 illustrated shot cards covering the proposed 240-second film.
- `performance-cards.pdf`: 22 illustrated dialogue cards with intention, emphasis and coverage notes.
- `documents/director-script-en.md`: annotated script with the canonical dialogue preserved.
- `documents/dialogue-performance.csv`: proposed local scene timings and performance directions; not measured final audio.
- `documents/shot-coverage.csv` and `shot-specifications.json`: shot-by-shot coverage and missing compositions.
- `documents/next-image-batch.md`: 15 concrete missing-keyframe briefs; not submitted or approved.
- `documents/review-findings.md`: observed continuity issues and evidence boundaries.
- `catalog.json`: card-to-reference mappings and input checksums.

All 79 PNGs are illustrated document layouts using existing project references. No new Kling scene generation was submitted in this pass. Keep the difference between real supplied photos, synthetic candidates, review layouts and accepted footage explicit.

The four new voice tests live at `04_audio/voice-tests/codex-opening-v1/` relative to the film root. This folder’s gallery links to them. The portable ZIP includes its own local audio copies and adjusted links. Original source photographs are not included as raw files in the portable ZIP; the Andre comparison board contains a review reproduction.

All images, voice tests, screenplay, keyframes, Elements and film take approvals remain pending. No final movie is claimed.
