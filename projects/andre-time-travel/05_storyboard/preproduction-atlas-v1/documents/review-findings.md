Scope: existing R1 still references, contact documents, selected full-size stills and the new document layouts. This is a preproduction review, not frame-by-frame movie QC or personal likeness approval.

## Findings that affect the next generation

1. **Andre’s costume is not yet locked.** The supplied February 2024 photograph shows a grey blazer and a pale striped shirt. The synthetic portrait and seated candidates propose a dark jacket and charcoal shirt. The atlas explicitly presents this as a choice. Obtain Andre’s likeness and wardrobe decision before creating the production Element or using synthetic portraits as continuity anchors.
2. **Eye pairs need continuity work.** Genghis state A has darker brows; state B has visibly silver brows and different skin creases. Oppenheimer’s pair changes brow darkness and gaze. Galileo’s pair changes apparent iris hue and framing. Caesar’s second command option reverses the intended screen direction. The atlas uses the first command option, but no pair is approved. Prefer one approved eye base for controlled expression changes in any later authorized work.
3. **The table has a recognizable motif but not a verified match cut.** The six plates repeat a grain/ring-stain idea, while camera orientation, apparent tabletop geometry and chair placement change. Trinity and the present-day plate look more along the table’s long axis. Match-cut close-ups need the same local grain, edge nick and hand position, independently of the wide environments. No physical dimensions have been measured or locked.
4. **Costume detail can add unwanted continuity.** Napoleon’s candidate includes several rings; Genghis has a conspicuous ring and blue patterned fabric. These are visible design choices, not sourced period conclusions. Decide whether to keep them before new shots. Galileo’s costume image includes generated manuscript writing; do not present that writing as a factual historical document or use it in a readable prop insert.
5. **Existing seated Andre images do not cover the five scenes.** Their backgrounds and table compositions are general candidates. Each shot card states the missing era-specific composition. A finished environment plate plus a separate portrait is not a finished keyframe.
6. **Speech and picture durations are different.** The 41 slots sum to 240 seconds. The new line timings are proposed editorial allocations. Longer answers cross multiple picture cuts, with reaction edits following the actual spoken cue. The four new opening files have measured container durations in their provenance record; the rest of the film has no measured final performance in this package.
