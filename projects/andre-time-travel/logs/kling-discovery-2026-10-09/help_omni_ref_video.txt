  --input            Fill one declared input slot as <name>=<url|path> (repeatable), for slots

  --poll             Wait up to N seconds for results before returning (0=off; bare flag=60)
Generation parameters (declared per model by the server — see `kling who_am_i`):
  any --<name> the model declares, snake_case or camelCase.
References are optional: a text-only prompt is valid when the model declares no required input.

MCP tool: omni_ref_video

Description:
Generate a video from mixed multimodal references with Kling Omni-Ref: text, images, videos, Element (subject) ids and audio URLs in a single submission. Call who_am_i first to discover the available models, each model's argument specification and its inputs. Image/video/audio URLs must be publicly accessible (e.g. the URL returned after uploading via file_upload). Bind subjects via the 'elements' argument (write <<<id>>> in the prompt; an id may be referenced multiple times). Reference videos as video_1..video_5 and audio as audio_1..audio_3. Returns a generationId immediately; poll query_tasks for the result.
